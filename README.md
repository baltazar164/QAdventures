# Q Adventures — Cebu Scooter Rental

Сайт проката скутеров и мотоциклов в Себу. Обычная статика без сборки:
что лежит в репозитории, то браузер и получает.

## Структура

```
index.html    # статичные блоки страницы
styles.css    # все стили
app.js        # витрина парка, календари, модалка бронирования, контактная форма
catalog.json  # офлайн-копия каталога — пишется роботом, руками не править
images/       # фото; images/catalog/ — тоже роботова, руками не править
tools/        # робот обновления офлайн-копии (запускается workflow'ом по расписанию)
```

Каталог, цены и фото страница берёт по публичному API из бэкенда при каждой
загрузке; если он недоступен — живёт на `catalog.json`.

## Ветки

- `main` — то, что раздаёт GitHub Pages;
- `dev` — рабочая;
- `static` — переписанный сайт, пока не слит в `dev`.

## Публикация

Публикация — это `git push` в `main`. Сборки нет.
